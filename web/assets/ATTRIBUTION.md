# Asset attribution

## motor.glb

- **Source:** generated by this repository's own script,
  `tools/build_motor.py` (trimesh; see plan section 17 — "generate it,
  don't hunt for it").
- **License:** CC0 / public domain. No external assets were used.
- **Regenerate:**
  `uv run --no-project --python 3.14 --with trimesh --with numpy python tools/build_motor.py`
- **Contract:** the node named `shaft` is the only spinning part; axis is
  +X with the origin at the housing centre; meshes named
  `housing` / `copper_windings` / `shaft` receive the temperature /
  current / stall glow hooks in `web/src/scene/motor3d.js`.

If this file is ever replaced with a downloaded model, record its source
URL and license here, and keep the shaft as a separately named node.
